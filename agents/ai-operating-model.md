# AI Operating Model

## Purpose

This repository is managed through human-led AI collaboration.

Humans remain responsible for:

- Vision
- Strategy
- Prioritization
- Product judgment
- Final approvals

AI assists with:

- Research
- Documentation
- Design exploration
- Engineering implementation
- Reviews
- Audits

---

## Repository Source of Truth

Repository files are authoritative.

Chat conversations are not authoritative.

When conflicts occur:

1. Repository artifacts win.
2. Decisions win over assumptions.
3. New decisions require documentation updates.

---

## Required Context Files

Before major work, review:

1. agents/project-context.md
2. agents/current-state.md
3. agents/decisions.md

---

## Documentation Rule

Approved decisions should update:

- Relevant artifact
- Dashboard
- Decision log

when appropriate.

---

## Product Philosophy

Favor:

- Simplicity
- Speed of learning
- Visible progress
- Iterative delivery
- Evidence over claims

Avoid:

- Over-engineering
- Premature optimization
- Unnecessary complexity
- Excessive planning

---

## Working Principle

Move quickly.

Validate continuously.

Document important decisions.

Maintain momentum.
